## Project Name :
    FITLOG

## Description: 
    FITLOG is a modern workout tracking web application built with Next.js. It allows users to explore workouts, view workout details, create a personal workout plan, and save their favorite exercises.


## Technologies Used
    1. Next.js
    2. React
    3. TypeScript
    4. Tailwind CSS
    5. DaisyUI
    6. React Icons
    7. React Toastify

## Features
    1. View detailed information about each workout
    2. Add workouts to today's plan
    3. Save workouts for later
    4. Mark exercises as done
    5. Remove workouts from today's plan or saved list
    6. Responsive design for mobile, tablet, and desktop devices
